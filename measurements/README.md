# Custom Headphone Measurements Directory

This directory is reserved for user-supplied headphone frequency response measurement files (CSV or AutoEQ TXT format).

## Format Guidelines
- CSV format: `Frequency, Raw_SPL` (e.g. `20, 80.5` ... `20000, 72.0`)
- AutoEQ TXT format: Frequency and SPL values separated by whitespace or tabs.

No synthetic or unverified physical headphone measurements are bundled by default.
